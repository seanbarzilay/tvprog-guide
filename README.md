# TV Guide

A Telegram Mini App — and an ordinary web page — for the current tvprog channel schedule, in Asia/Jerusalem time.

**Live:** https://seanbarzilay.github.io/tvprog-guide/

The page reads [`guide.json`](guide.json), a snapshot of what’s on now, what’s on next, and the upcoming grid. A timer on the home machine refreshes that file when the lineup changes.

Open it in Telegram via the bot’s Mini App link once the app is registered with BotFather, or visit the address above in any browser.
